# JYBToolApp 全应用需求

## 产品目标

为维护多个 Git 仓库和 Xcode 项目的内部开发者提供一致的 macOS 工作台。开发者应能在执行前看清目标范围，在执行中了解进度，并在完成后区分成功、跳过和失败项。

## 用户与范围

主要用户是每天维护多个券商、公版依赖和 Xcode 工程的内部开发者。首轮覆盖私版工具、公版分支切换、仓库更新、Tag 管理、统一导航和统一日志。旧版主仓库子模块切换保留兼容入口并标记为过时。

## 核心任务

### 私版券商切换

- 选择含 `repos.yaml` 的配置仓库，读取并检查仓库状态。
- 执行前逐仓显示当前分支、目标分支、路径和工作区状态。
- 用户确认后逐仓切换；脏工作区按现有自动保存与恢复规则处理。
- 单仓失败时继续其他仓库，并汇总成功、跳过、失败及原因。

### 分支切换（已过时）

- 导航与页面明确显示“已过时”，保留既有操作供兼容使用。
- 不作为新流程推荐入口；本轮不扩展其能力。

### 公版分支切换

- 选择主工程，刷新主分支并读取 `fastlane/repos.yml`。
- 逐仓查看当前状态和 `repos.yml` 中的目标分支，再确认批量切换。
- `repos.yml` 中的 `tag` 字段不作为切换目标；此页面只切换分支。
- 独立显示切换目标和逐仓操作结果，不包含拉取和 Tag CRUD 入口。

### 公版仓库更新

- 使用独立页面读取 `repos.yml`，列出主仓库与全部依赖仓库。
- 每仓可单独选择，支持全选；默认全选。更新操作只处理用户选择的仓库，只拉取当前分支，不切换分支。
- 脏工作区按现有自动暂存与恢复规则处理。
- 执行前确认范围；执行时沿用现有拉取最新逻辑，完成后逐仓展示成功、跳过、失败及原因。
- 详细规则以 `docs/public-repo-sync/PRD.md` 为准。

### 公版 Tag 管理

- 使用独立页面多选配置中的主仓库或依赖仓库；提供全选与取消全选。
- 操作区与仓库选择区分开展示。用户填写一组 Tag 名称和附注后，对所有勾选仓库的当前 HEAD 创建同名 annotated Tag 并推送到 `origin`。
- 页面不读取或展示已有 Tag。执行前确认中列出所选仓库；单仓失败不阻断其他仓库，并逐仓汇总成功、推送失败和创建失败。
- 创建成功但推送失败时，保留本地 Tag，并允许针对该仓库单独重试推送。
- 批量设置并推送须明确确认；Tag 名称按 Git ref 规则校验。
- 本页管理 Git Tag，不修改 `repos.yml` 中的切换目标。

### 私版项目复制

- 配置一个或多个源/目标路径与旧、新前缀。
- 开始前校验路径和前缀，并预览复制范围及替换摘要。
- 运行时展示步骤进度；结束时展示计数、警告、错误和可继续处理的建议。
- 保留受保护关键词、配置文件修改和现有项目重命名能力。

### 统一导航与日志

- 左侧按“公版”和“私版”分组。公版依次展示分支切换、仓库更新、Tag 管理和分支切换（已过时）。
- 页面使用一致的标题、说明、配置区、预览列表和主操作位置。
- 日志支持级别筛选、清空、展开/收起、调整高度和复制文本；新日志不可遮挡当前操作。

工具归组：公版包含分支切换、仓库更新、Tag 管理和分支切换（已过时）；私版包含券商仓库切换与项目复制。

## 验收标准

- 所有公版与私版页面均可从分组导航发现；旧版分支切换入口显示已过时状态。
- 批量执行前能核对仓库范围、路径和目标版本。
- 仓库更新列出主仓库和所有依赖仓库；用户可逐仓选择或全选，且只更新所选项。
- 执行中有明确进度；结束后有汇总和逐项结果，部分失败时保留成功结果。
- 路径、配置、分支或 Tag 无效时给出可读说明和恢复入口，不静默失败。
- Tag 页面支持多仓库选择与全选；对所选仓库统一创建并推送同一 Tag，不读取已有 Tag。执行前确认范围、逐仓展示结果，推送失败后可按仓库重试。
- 界面在 macOS 14.6+、浅色/深色外观、常用窗口尺寸下可读且支持键盘操作。
- 核心 Git 与复制逻辑有单元测试，Swift 6 构建与测试通过。
