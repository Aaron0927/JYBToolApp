# JYBToolApp 全应用需求

## 产品目标

为维护多个 Git 仓库和 Xcode 项目的内部开发者提供一致的 macOS 工作台。开发者应能在执行前看清目标范围，在执行中了解进度，并在完成后区分成功、跳过和失败项。

## 用户与范围

主要用户是每天维护多个券商、公版依赖和 Xcode 工程的内部开发者。首轮覆盖四项现有工具、统一导航和统一日志。现有功能保持可用；功能增删需先在需求中确认。

## 核心任务

### 私版券商切换

- 选择含 `repos.yaml` 的配置仓库，读取并检查仓库状态。
- 执行前逐仓显示当前分支、目标分支、路径和工作区状态。
- 用户确认后逐仓切换；脏工作区按现有自动保存与恢复规则处理。
- 单仓失败时继续其他仓库，并汇总成功、跳过、失败及原因。

### 主仓库子模块切换

- 选择主仓库和目标分支，读取该分支的子模块配置。
- 执行前展示主仓库及各子模块当前状态与目标分支。
- 确认后切换；逐项展示结果，单个子模块失败不隐藏其他结果。

### 公版依赖仓库

- 选择主工程，刷新主分支并读取 `fastlane/repos.yml`。
- 逐仓查看当前状态、目标分支或 Tag，再确认批量切换。
- 支持已有的一键拉取全部仓库，以及按配置分支或 Tag 切换。
- 批量操作显示仓库范围和逐仓结果。
- 原型中的 Tag 创建、推送、删除和目标版本编辑尚未接入应用，本轮不把它们作为现有能力或上线验收项。
- 将 `docs/public-repo-sync/PRD.md` 的拉取行为作为本模块的具体需求来源并保持一致。

### 私版项目复制

- 配置一个或多个源/目标路径与旧、新前缀。
- 开始前校验路径和前缀，并预览复制范围及替换摘要。
- 运行时展示步骤进度；结束时展示计数、警告、错误和可继续处理的建议。
- 保留受保护关键词、配置文件修改和现有项目重命名能力。

### 统一导航与日志

- 左侧按“公版”和“私版”分组，启动后直接进入首个工具。
- 页面使用一致的标题、说明、配置区、预览列表和主操作位置。
- 日志支持级别筛选、清空、展开/收起、调整高度和复制文本；新日志不可遮挡当前操作。

工具归组：主仓库子模块切换与公版依赖仓库归入“公版”；私版券商仓库切换与私版项目复制归入“私版”。

## 验收标准

- 四项工具的主要任务均可从导航发现并完成，原有核心操作保持可用。
- 批量执行前能核对仓库范围、路径和目标版本。
- 执行中有明确进度；结束后有汇总和逐项结果，部分失败时保留成功结果。
- 路径、配置、分支或 Tag 无效时给出可读说明和恢复入口，不静默失败。
- 界面在 macOS 14.6+、浅色/深色外观、常用窗口尺寸下可读且支持键盘操作。
- 核心 Git 与复制逻辑有单元测试，Swift 6 构建与测试通过。
