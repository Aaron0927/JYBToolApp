# 原型与 UI 规则

## 设计目标

采用 macOS 原生控件和系统语义，保持克制、清晰、可扫描。工具页面共用相同的信息顺序：页面标题与说明、工作区选择、配置与预览、主操作、结果反馈。

主导航按“公版”和“私版”分组。公版依次提供分支切换、仓库更新、Tag 管理与分支切换（已过时）；私版提供券商仓库切换与项目复制。过时状态需同时出现在导航和页面提示中。

## 原型规则

- `docs/jybtoolapp-overall-prototype.html` 是可点击交互原型；所有仓库、路径和操作结果均为演示数据。
- 覆盖首次进入、配置缺失、可执行、执行中、部分失败、成功和失败状态。
- Git 批量操作与项目复制都先显示操作范围和目标，再展示确认结果。
- Tag 管理是独立页面；Tag 操作区与仓库选择区分开。仓库区支持多选主仓库/依赖仓库和全选，操作区对所选仓库统一设置并推送同一 Tag；页面不读取已有 Tag。确认时列出全部目标，完成后逐仓显示结果，并为本地已创建但推送失败的仓库提供重试入口。
- 分支切换页只依据 `repos.yml` 切换分支；其中的 `tag` 字段不作为切换目标。
- 仓库更新页读取 `repos.yml` 后列出主仓库和全部依赖仓库；列表支持逐仓勾选与全选，默认全选，更新只作用于所选仓库并沿用现有拉取行为。
- 原型不访问本机仓库、文件系统、Xcode 或网络服务。

## SwiftUI 视觉与交互

- 使用 `NavigationSplitView`、`Form`、`GroupBox`、系统按钮样式、系统材料与语义颜色。
- 共用 `ToolUI` 包中的 `ToolPageHeader`、`ToolPanel`、`ToolStatusBadge`、`ToolValueRow`，统一页面标题、分区、状态标签和路径呈现。
- 主应用窗口保持可调整尺寸，初始建议尺寸不低于 740×560；窄窗口优先让内容滚动，日志面板可收起或调整高度。
- 使用系统字体、系统间距、语义颜色和系统控件；浅色与深色外观都遵循系统颜色，不在控件中固定背景色。
- 主操作使用 `.borderedProminent`；删除或覆盖等危险操作用明确文案和确认步骤。
- 状态同时用文字与图标表达，不能只依赖颜色；错误信息保留可复制的路径和原因。
- 优先动态字体和系统间距；窄窗口时内容可滚动，按钮不能被日志面板遮挡。
- 控件有可访问标签、键盘焦点、清晰的禁用状态和明确的键盘默认操作；日志筛选及面板高度调整可通过键盘访问。

## 页面状态

路径和配置操作统一展示空状态、读取中、可执行、执行中、成功和失败。列表需区分当前值与目标值；批量结果按仓库逐项呈现，并在顶部汇总成功、跳过和失败数量。
