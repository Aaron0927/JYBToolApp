# PRD：公版仓库更新

## 1. 需求背景

公版主工程由主仓库及 `fastlane/repos.yml` 声明的依赖仓库组成。开发者需要先确认本次更新范围，再选择要拉取最新内容的仓库。

## 2. 用户目标

选择主工程目录并读取 `repos.yml` 后，工具列出全部相关仓库；用户可逐仓选择或全选，只更新所选仓库。

## 3. 功能流程

1. 用户选择包含 `fastlane/repos.yml` 的主工程目录。
2. 工具解析配置，列出主仓库和配置中声明的所有依赖仓库。
3. 默认全选；用户可以逐项勾选、取消，或使用全选/取消全选。
4. 用户确认后，仅更新选中的仓库当前分支。
5. 更新完成后展示逐仓结果。

## 4. 更新规则

- 不自动切换分支、不自动合并；更新使用 `git pull --ff-only`，避免自动创建合并提交。
- 工作区存在本地更改时，沿用当前自动 stash 与恢复规则；恢复冲突时保留 stash 并提示原因。
- 未选择的仓库不执行 pull。
- 无效路径、非 Git 仓库、detached HEAD、没有 upstream 或远程分支不存在时，该仓库显示跳过原因；其他仓库仍照常更新。
- 更新单仓失败时继续处理其他已选仓库，并展示成功、跳过、失败数量与逐仓原因。

## 5. 验收标准

- 页面可从独立的“仓库更新”导航入口打开。
- 读取配置后，主仓库和 `repos.yml` 中的全部仓库均显示为独立可选项。
- 用户可逐仓勾选或全选；确认后只更新所选仓库。
- 更新完成后可见逐仓成功、跳过或失败状态及原因。
- 单仓失败不会阻止其他所选仓库继续处理。
